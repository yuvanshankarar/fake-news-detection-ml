# Fake News Detection using Machine Learning and NLP

## Overview
This project detects whether a news article is REAL or FAKE using Machine Learning and Natural Language Processing techniques.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression

## Features
- Text preprocessing
- TF-IDF vectorization
- Fake/Real news classification
- Accuracy evaluation

## Dataset
Custom dataset containing REAL and FAKE news samples.

## Output
The model predicts whether input news is REAL or FAKE.
